## Сборка сайта
- `npm run build` — сборка + генерация страниц спектаклей и педпроектов + sitemap/robots
- `npm run dev` — dev-сервер (режим разработки; страницы спектаклей/педпроектов только в dist после сборки)
- Публикация: push в ветку `main` репозитория Sashka350/pavel-pronin-site → GitHub Actions собирает и деплоит на Pages.
  - Базовый путь задаётся переменной `BASE_PATH` (по умолчанию `/pavel-pronin-site/`), адрес сайта — `SITE_URL` (по умолчанию https://sashka350.github.io/pavel-pronin-site). Для кастомного домена: `BASE_PATH=/` и `SITE_URL=https://pavelpronin.me`.
- Публичный адрес сайта: https://sashka350.github.io/pavel-pronin-site/
