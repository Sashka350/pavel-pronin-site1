10. ЭТАПЫ РАБОТЫ (технические шаги)
================================================================================

ЭТАП 1: ИНИЦИАЛИЗАЦИЯ ПРОЕКТА (1-2 часа)
──────────────────────────────────────────
1.1. Создать структуру папок (см. п. 3)
1.2. Инициализировать npm-проект (package.json)
1.3. Установить Vite: npm i -D vite
1.4. Настроить vite.config.js (dev-сервер, сборка)
1.5. Создать базовые CSS-файлы (variables.css, base.css)
1.6. Создать index.html с базовой разметкой
1.7. Настроить hot reload
1.8. Запустить dev-сервер (npm run dev)
1.9. Проверить, что всё работает

ЭТАП 2: ДИЗАЙН-СИСТЕМА И LAYOUT (3-4 часа)
────────────────────────────────────────────
2.1. Описать CSS custom properties (цвета, шрифты, отступы)
